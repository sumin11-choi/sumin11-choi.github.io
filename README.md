# 최수민의 베이커리 레시피

손으로 적어둔 베이킹 노트 20장을 HTML로 정리한 사이트입니다.

**https://sumin11-choi.github.io/**

## 구성

- `index.html` — 전체 레시피 목록 (검색 · 카테고리 필터)
- `recipe/*.html` — 레시피별 상세 페이지 (재료 · 만드는 법 · 원본 노트 사진)
- `images/`, `thumbs/` — 원본 노트 사진
- `style.css` — 공통 스타일

## 수록 레시피

1. **에그타르트** (파이·타르트) — 190℃ · 예열 후 30~35분
2. **초코 케이크 (1호)** (케이크) — 180℃ 예열 → 170℃ 25분
3. **제누와즈 (기본)** (케이크) — 160℃ · 35~37분
4. **브라우니** (브라우니) — 170℃ · 20분
5. **브라우니 쿠키** (쿠키) — 180℃ · 10분
6. **초코 머핀** (머핀·번) — 160℃ · 22분
7. **머랭쿠키 & 버터쿠키** (쿠키) — 머랭 95~100℃ 90분 / 버터쿠키 170℃ 10~15분
8. **베이글** (빵) — 반죽 · 발효 중심 (굽기 온도는 원본에 미기재)
9. **소금빵** (빵) — 원본에 굽기 온도 미기재
10. **전자레인지 머그 쿠키** (쿠키) — 전자레인지 1분
11. **모카번** (머핀·번) — 185℃ · 15분
12. **브라우니 (곰쓴베이킹)** (브라우니) — 170℃ 예열 · 30~35분
13. **커피콩 쿠키** (쿠키) — 160℃ · 12분
14. **초코칩 쿠키 (큰 사이즈)** (쿠키) — 180℃ · 13분
15. **아몬드 초코칩 쿠키** (쿠키) — 180℃ · 10분
16. **초코칩 쿠키 (소량)** (쿠키) — 180℃ 예열 후 10분
17. **피낭시에** (구움과자) — 185~190℃ · 14~15분 (한 판씩)
18. **초코 마들렌** (구움과자) — 190℃ 예열 → 170℃ 12분
19. **상하이 버터떡** (기타) — 200℃ 10분 → 180℃ 20분 (총 30분)
20. **계란찜** (기타) — 가스레인지 · 뚜껑 덮고 익히기

계량이나 글씨가 애매한 부분은 각 상세 페이지의 원본 노트 사진을 기준으로 확인해 주세요.
